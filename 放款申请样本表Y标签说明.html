Y 标签说明：54 个核心列 + 延伸口径

目标表 model.tmp_eliam_wagego_dwd_loan_apply_label，一行一条借款申请。下面用真实借据 LN00000033，把核心 54 个 y_* 一列一列讲；mob 新增 60 列、due 新增 20 列，在最后汇总。

核心 54 列 = due 10 + fpd 10 + obs 4 + mob 30 ｜ 延伸 80 列 = mob 60 + due 20 ｜ 合计 134 个 y_* ｜ 观察日 obs_dt = 2026-10-22

先看这条样本借据

LN00000033 · 2026-07-28 放款 50 元 · 2026-08-02 到期 · 2026-08-09 首期实还，晚 7 天，随后结清。

current = 当天还欠几天；hist = 历史上最深欠几天。本例每次看都是 current 0、hist 7：早就结清了，但曾经晚还 7 天。下面所有标签都从这两个数来。

due

到期后第 31 天：当天 vs 曾经

① 算日子：due + 31 = 2026-09-02。② 取这一天的快照：current = 0、hist = 7，记作 label_dpd = 0、label_hist_dpd = 7。③ 10 列都从这两个数来。

due+

due 的两个延伸观察窗

10 个指标与上面的 due 完全一样，只换观察日：到期后第 N 个月的同一天，ADD_MONTHS(init_due_date, N)，N = 2 / 3。不是自然月末；月末口径在 y_mob_due2/3。

口径观察日公式列名前缀本例观察日
到期后第 2 个月ADD_MONTHS(init_due_date, 2)y_due_m2_*10-02，已成熟
到期后第 3 个月ADD_MONTHS(init_due_date, 3)y_due_m3_*11-02，未成熟

每个口径 10 列，后缀与 due 一样：dpd、ever_dpd、ovd、ever_ovd、5plus、30plus，各带 cnt / amt。本例 m2 快照 current 0 / hist 7 → y_due_m2_ovd_cnt = 0、y_due_m2_ever_5plus_cnt = 1；m3 = 11-02 还没到 obs_dt，10 列全 NULL。m2 = 10-02 与 y_mob_due2 的 10-31 不是同一天。

fpd

首期在到期后 X 天内还没还？

只看首期（period_no = 1）。label_obs_day 先取 due+31 快照的首还日；没有就取 obs 快照首还日（需 ≤ due+31）；再没有就截在 due+31。本例 = 2026-08-09。五个窗口：due+3 = 08-05、due+7 = 08-09、due+14 = 08-16、due+15 = 08-17、due+30 = 09-01。

每个口径 30 列 = 3 个 N × 10 个指标，列名后缀与原来完全一致。本例 due1、day30、day60 的快照都是 current 0 / hist 7 → 5plus_cnt = 0、ever_5plus_cnt = 1；due2 / due3 / day90 未成熟，坏标签为 NULL。due1 = 09-30 与原来的 mob2 同一天，是日期巧合，不是同一口径。

用之前记住 4 件事

  • 算坏率先分分子分母。FPD / MOB（含 mob 的 due / day 口径）用 obs_cnt 作分母、坏标签作分子；due 族（含 m2 / m3）先确认对应观察日已成熟。不要把 NULL 当 0。
  • due 和 obs 都分“当天”和“曾经”。current 看当天，hist 看历史最深；本例就是当天 0、曾经 1。
  • 阈值边界：5plus 是 ≥ 5，30plus 是 > 30。刚好 30 天不算 30+。
  • 金额标签：坏样本记 real_amount，好样本记 0。唯一例外是所有 mob 的 obs_amt（y_mobN / y_mob_dueN / y_mob_dayXN），它是分母金额。

被拒、未放款、没有借据的申请也会保留一行，但 Y 列是 NULL 或 0：due / obs / mob 整族 NULL，fpd 的 obs_cnt = 0、ovd_cnt = NULL。
