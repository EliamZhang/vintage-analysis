口径分母current 分子ever 分子快照
FPD7 / FPD15principaly_fpdN_ovd = 1—obs 快照；y_fpdN_obs = 1 门控
MOB0–4estimate_principal_remaining_mobNdpd_days_mobN ≥ 5 / > 30dpd_days_ever_mobN ≥ 5 / > 30MOB1–4 月末当天；MOB0 月末后 7 天内

FPD：SUM(CASE WHEN y_fpdN_ovd = 1 THEN principal ELSE 0 END) / SUM(CASE WHEN y_fpdN_obs = 1 THEN principal ELSE 0 END)
MOB：SUM(CASE WHEN dpd_days_mobN >= 5 THEN estimate_principal_remaining_mobN ELSE 0 END) / SUM(estimate_principal_remaining_mobN)；把 dpd_days_mobN 换成 dpd_days_ever_mobN 就是 ever 口径。

principal 在放款成功时等于 real_amount；MOB 的 dpd_days_* 是快照原始 DPD，NULL 记 0，没有快照时整组 NULL。MOB1–3 与 Y 标签同快照，可直接对比笔数率与金额率。MOB0 和 MOB4 只有金额指标，没有 Y 标。

本例：FPD7 / FPD15 都是 0 / 50 = 0%；MOB1 / MOB2 余额为 0，不进分母，但 ever DPD 仍是 7；MOB0 余额 50，current / ever 都是 0。

用之前记住 3 件事

  • obs 是门控，不是坏标志。FPD / MOB 都用 obs 做成熟判断；笔数率的分母是 obs = 1，金额率的分母另看上一节。窗口未到、缺快照时坏标签为 NULL，不要当 0。
  • 金额率不要混基数。FPD 用 principal（放款本金）；MOB 用 estimate_principal_remaining_mobN（时点余额）。余额为 0 的样本不进 MOB 分母。
  • 阈值边界固定。5plus 是 ≥ 5，30plus 是 > 30；FPD 没有 ever，ever 只用于 MOB。

被拒、未放款、没有借据的申请也保留一行：FPD obs = 0、ovd = NULL；MOB 整族 NULL。
