Y 标签与金额逾期率指标说明

目标表 model.tmp_eliam_wagego_dwd_loan_apply_label，一行一条借款申请。Y 标签共 19 个，全部为笔数口径：FPD 4 + MOB 15。金额逾期率另用 1 个放款金额列 principal 和 15 个 MOB 中间指标列，这些都不是 Y 标。下面用真实借据 LN00000033 说明。

观察截止 obs_dt = 2026-10-22 ｜ FPD 窗口 due+7 / due+15 ｜ MOB 观察点 = 放款后第 N 个自然月末 ｜ 金额指标覆盖 MOB0–4，MOB1–3 与 Y 标同一张月末快照

先看这条样本借据

LN00000033 · 2026-07-28 放款 50 元 · 2026-08-02 到期 · 2026-08-09 首期实还，晚 7 天，随后结清。

current = 当天还欠几天；hist = 历史上最深欠几天。NULL 在 MOB 金额指标里记 0，但没有快照时整组为 NULL。本例结清后 current 一直是 0，hist 一直是 7。

fpd

Y 标签：FPD7 / FPD15（4 个）

只看首期（period_no = 1）。label_obs_day 取 obs 快照的首还日；没有首还记录就用 obs_dt。本例 = 2026-08-09，两个窗口 due+7 = 08-09、due+15 = 08-17。

标签含义怎么算本例
y_fpd7_obs_cntdue+7 窗口能否判定LEAST(首还日或 obs_dt, due+7) < obs_dt，且 is_deal = 1、有借据1
y_fpd7_ovd_cnt首期是否晚于 due+7y_fpd7_obs_cnt = 1 时，label_obs_day > due+70
y_fpd15_obs_cntdue+15 窗口能否判定LEAST(首还日或 obs_dt, due+15) < obs_dt，且 is_deal = 1、有借据1
y_fpd15_ovd_cnt首期是否晚于 due+15y_fpd15_obs_cnt = 1 时，label_obs_day > due+150

obs_cnt 是成熟标志兼分母，不是坏标志；窗口未到时 obs_cnt = 0、ovd_cnt = NULL。窗口嵌套：窗口越长，坏样本只会越少。FPD15 是主标签。

mob

Y 标签：MOB1 / MOB2 / MOB3（15 个）

放款日 07-28 → MOB1 = 08-31、MOB2 = 09-30、MOB3 = 10-31。每个 N 有 5 个标签：obs_cnt（成熟/分母），以及 current 口径的 5plus_cnt / 30plus_cnt 和 ever 口径的 ever_5plus_cnt / ever_30plus_cnt。四个逾期标签都取该月末快照：current 看 current_overdue_days，ever 看 hist_overdue_days。

obs_cnt 是成熟标志，不是坏标志；未放款时整族 NULL。月末已过但当天没有快照时，obs_cnt = 1，四个逾期标签为 NULL。5plus / 30plus 看当天 current，ever_* 看 hist；阈值边界：5plus 是 ≥ 5，30plus 是 > 30。

fpd

金额逾期率：FPD 用 principal（1 个中间指标）

FPD 是单一时点，没有余额轨迹，不需要额外中间列。金额口径直接用 principal：放款成功时等于 real_amount，未放款为 NULL。分子分母都用它，成熟由 y_fpdN_obs_cnt 门控。

列含义在金额率中的角色本例
principal放款本金（= 放款成功时的 real_amount）分子和分母的金额基数50
y_fpd7_obs_cnt / y_fpd15_obs_cnt窗口是否成熟分母门控1 / 1
y_fpd7_ovd_cnt / y_fpd15_ovd_cnt是否首期逾期分子门控0 / 0

公式：SUM(CASE WHEN y_fpdN_ovd_cnt = 1 THEN principal ELSE 0 END) / SUM(CASE WHEN y_fpdN_obs_cnt = 1 THEN principal ELSE 0 END)。本例 FPD7 / FPD15 都是 0 / 50 = 0%。若要用申请金额加权，可改用 real_amount，但仍以 obs_cnt = 1 限定成熟样本。

mob

金额逾期率：MOB 用 15 个非 Y 列（MOB0–4）

每个 MOB 有 3 个中间指标：剩余本金作分母，current / ever DPD 作分子条件。dpd_days_mobN 和 dpd_days_ever_mobN 是快照的原始 DPD，NULL 记 0；没有快照时整组为 NULL。MOB1–3 与同 N 的 Y 标签取同一张月末快照，可以直接对比笔数率与金额率。

公式（current 口径，对应 y_mobN_5plus_cnt / y_mobN_30plus_cnt）：SUM(CASE WHEN dpd_days_mobN >= 5 THEN estimate_principal_remaining_mobN ELSE 0 END) / SUM(estimate_principal_remaining_mobN)。把 dpd_days_mobN 换成 dpd_days_ever_mobN 就是 ever 口径，对应 y_mobN_ever_5plus_cnt / y_mobN_ever_30plus_cnt。本例 MOB1 / MOB2 余额为 0，不进分母，但 ever DPD 仍是 7；MOB0 余额 50，current / ever 都是 0。

快照选择：MOB1–4 取月末当天快照，与 Y 标签完全一致；MOB0 没有对应的 Y 标签，允许月末后 7 天内，优先月末及之前。没有快照就整组 NULL。MOB4 只有金额指标，没有对应的 Y 标签。

用之前记住 4 件事

  • Y 标签先分分子分母。FPD / MOB 都用 obs_cnt 作成熟门控和分母；窗口未到时坏标签为 NULL，不要把 NULL 当 0。MOB 的 5plus / 30plus 看 current，ever_* 看 hist。
  • 金额率不要混基数。FPD 用 principal（放款本金）；MOB 用 estimate_principal_remaining_mobN（时点余额），两者不能互相替代。MOB1–3 与 Y 标签同快照，笔数率和金额率可以直接放在一起看。
  • 余额为 0 的样本不进 MOB 分母。提前结清的借据会拉小分母，报金额率时同时报分母金额；ever DPD 仍保留历史逾期。
  • 阈值边界：5plus 是 ≥ 5，30plus 是 > 30。刚好 30 天不算 30+；金额率可以按 5 / 30 或自定义阈值切。

被拒、未放款、没有借据的申请也会保留一行：FPD 的 obs_cnt = 0、ovd_cnt = NULL；MOB 整族 NULL。
