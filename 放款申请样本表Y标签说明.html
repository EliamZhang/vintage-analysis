MOB 取自然月末，不是放款后 30 天。obs 是成熟标志兼笔数率分母；窗口未到时坏标签为 NULL（即使已结清），不要当 0。阈值边界：5plus 是 ≥ 5，30plus 是 > 30。

03

金额逾期率

FPD 用放款本金，MOB 用时点剩余本金；Y 标签走笔数口径，金额率用对应的中间列。

FPD 金额率

principal
SUM(CASE WHEN y_fpdN_ovd = 1 THEN principal ELSE 0 END) / SUM(CASE WHEN y_fpdN_obs = 1 THEN principal ELSE 0 END)

分母是窗口成熟（obs = 1）的放款本金，分子是其中首还晚于 due+N 的本金。

MOB 金额率

余额 + DPD
SUM(CASE WHEN dpd_days_mobN >= 5 THEN estimate_principal_remaining_mobN ELSE 0 END) / SUM(estimate_principal_remaining_mobN)

快照：MOB1–4 取月末当天，MOB0 允许月末后 7 天。ever 把 dpd_days_mobN 换成 dpd_days_ever_mobN。

principal 在放款成功时等于 real_amount；MOB 的 dpd_days_* 是快照原始 DPD，NULL 记 0，没有快照时整组 NULL。MOB1–3 与 Y 标签同快照，可直接对比笔数率与金额率。MOB0 和 MOB4 只有金额指标，没有 Y 标。

字段口径以 wagego_01_放款申请样本表及Y标签.sql 为准。
