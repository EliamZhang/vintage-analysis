current = 当天还欠几天；hist = 历史上最深欠几天。本例每次看都是 current 0、hist 7：早就结清了，但曾经晚还 7 天。这也是为什么主标签用 ever 口径。

fpd

首期逾期：FPD7 / FPD15

只看首期（period_no = 1）。label_obs_day 先取 due+31 快照的首还日；没有就取 obs 快照首还日（需 ≤ due+31）；再没有就截在 due+31。本例 = 2026-08-09。两个窗口：due+7 = 08-09、due+15 = 08-17。

obs_cnt 是成熟标志兼分母，不是坏标志；窗口未到时 obs_cnt = 0、ovd_cnt = NULL。窗口嵌套：窗口越长，坏样本只会越少。FPD15 是选型主标签；FPD14 与之重叠 93.6%，已删。

mob

放款后第 N 个自然月末：成熟标志 + ever 阈值

放款日 07-28 → MOB1 = 08-31、MOB2 = 09-30、MOB3 = 10-31。每个 N 保留 3 列：obs_cnt（成熟/分母）、ever_5plus_cnt、ever_30plus_cnt。

金额逾期率：用这 15 个非 Y 列

53 个金额列都能机械还原：44 个坏账 *_amt = 对应 *_cnt × real_amount；9 个 mob obs_amt = obs_cnt × real_amount。FPD14 与 FPD15 重叠 93.6%；current 阈值在短期产品上大量为 0，所以 MOB 只保留 ever。due 与 obs 整族删除：观察时点不固定，且与 FPD/MOB 时间轴重叠。

用之前记住 4 件事

  • 算坏率先分分子分母。FPD / MOB 用 obs_cnt 作分母；不要把 NULL 当 0。
  • ever 是主口径。短期借据到 MOB 时点大多已结清，current 看不出历史坏；ever 用 hist_overdue_days，不会漏掉已结清的坏样本。
  • 阈值边界：5plus 是 ≥ 5，30plus 是 > 30。刚好 30 天不算 30+。
  • 金额逾期率用余额，不用放款金额。分母用 estimate_principal_remaining_mobN；real_amount 只适合放款金额加权。

被拒、未放款、没有借据的申请也会保留一行，但 Y 列是 NULL 或 0：mob 整族 NULL，fpd 的 obs_cnt = 0、ovd_cnt = NULL。
