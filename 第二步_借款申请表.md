# 第二步：建借款申请表

## 目标

一行一个 `loan_no`，覆盖全部借款申请：放款成功、审核拒绝、过期、放款失败、处理中。

## 数据源

- 底表：`ods_ewa.aus_ewa_loan_biz_t_loan_application`（原始表）
- 补充：`model.tmp_eliam_wagego_application`（第一步自建，只取 `app_id`、`retry_count`、`application_id`）
- 关联键：`loan_no = flow_id`，且只取 `event_type = 'loan_apply'`、`flow_id LIKE 'LN%'`

## 对账结论（2026-10-20 导出）

- 原始申请表 33,502 行，`isactive = 1` 后 33,491 行，`loan_no` 无重复
- 主表 `loan_apply` 33,478 行；与原始表匹配 33,474 行，其中 `isactive = 1` 的 33,464 行
- 27 笔 2026-09-20 的 `EXPIRED` 申请在主表没有对应事件，但原始表有 → 必须以原始表为底表
- 主表多出 4 笔：3 笔 2026-10-20 03:26 后的新申请（原始表导出更早）+ 1 笔非 LN 的 `APP...` 事件 → 关联时过滤 `LIKE 'LN%'`
- 主表 `status = 20` 只代表放款策略执行成功，不代表审批通过；申请结果必须用原始表 `status`
- 原始表 `listing_id` 只在放款成功后才有值；放款金额、期限仍要等资产/放款标的表

`isactive = 1` 状态分布：

| apply_status | 含义 | 笔数 |
|---|---|---:|
| `DISBURSE_SUCCESS` | 放款成功 | 25,549 |

## SQL

```sql
DROP TABLE IF EXISTS model.tmp_eliam_wagego_loan_apply;
CREATE TABLE model.tmp_eliam_wagego_loan_apply AS
WITH base AS (
    SELECT
         a.loan_no
        ,a.user_id
        ,a.listing_id
        ,a.status                                             AS apply_status
        ,a.fail_reason
        ,a.loan_stage
        ,CAST(a.inserttime AS TIMESTAMP)                      AS apply_time
        ,CAST(a.apply_disburse_time AS TIMESTAMP)             AS apply_disburse_time
        ,CAST(a.expire_time AS TIMESTAMP)                     AS expire_time
        ,CAST(a.unbanned_time AS TIMESTAMP)                   AS unbanned_time
        ,CAST(a.updatetime AS TIMESTAMP)                      AS update_time
        ,a.dw_cre_date
        ,a.dw_upd_date
        ,ROW_NUMBER() OVER (
             PARTITION BY a.user_id
             ORDER BY CAST(a.inserttime AS TIMESTAMP), a.loan_no
         )                                                    AS apply_seq
    FROM ods_ewa.aus_ewa_loan_biz_t_loan_application a
    WHERE CAST(a.isactive AS INT) = 1
)
SELECT
     b.loan_no
    ,b.user_id
    ,e.application_id                                         -- 仅展示，不参与关联
    ,e.app_id
    ,b.listing_id
    ,b.apply_status
    ,CASE b.apply_status
         WHEN 'DISBURSE_SUCCESS' THEN '放款成功'
         WHEN 'DISBURSE'         THEN '放款中'
         WHEN 'DISBURSE_FAILED'  THEN '放款失败'
         WHEN 'AUDIT'            THEN '审核中'
         WHEN 'AUDIT_APPROVED'   THEN '审核通过'
         WHEN 'AUDIT_REJECTED'   THEN '审核拒绝'
         WHEN 'EXPIRED'          THEN '已过期'
         WHEN 'INFO_CHANGED'     THEN '信息变更'
         ELSE b.apply_status
     END                                                      AS apply_status_desc
    ,CASE WHEN b.apply_status = 'DISBURSE_SUCCESS' THEN 1 ELSE 0 END AS is_disburse_success
    ,CASE WHEN b.apply_status = 'AUDIT_REJECTED'   THEN 1 ELSE 0 END AS is_reject
    ,CASE WHEN b.apply_status = 'EXPIRED'          THEN 1 ELSE 0 END AS is_expired
    ,CASE WHEN b.apply_status = 'DISBURSE_FAILED'  THEN 1 ELSE 0 END AS is_disburse_failed
    ,CASE WHEN b.apply_status IN ('AUDIT', 'AUDIT_APPROVED', 'DISBURSE')
          THEN 1 ELSE 0 END                                   AS is_processing
    ,b.fail_reason
    ,b.loan_stage
    ,b.apply_time
    ,TO_DATE(b.apply_time)                                    AS apply_date
    ,DATE_FORMAT(b.apply_time, 'yyyy-MM')                     AS apply_month
    ,CASE WHEN b.apply_status = 'DISBURSE_SUCCESS'
          THEN b.apply_disburse_time END                      AS disburse_time
    ,CASE WHEN b.apply_status = 'DISBURSE_SUCCESS'
          THEN (UNIX_TIMESTAMP(b.apply_disburse_time) - UNIX_TIMESTAMP(b.apply_time)) / 3600.0
     END                                                      AS apply_to_disburse_hours
    ,b.expire_time
    ,b.unbanned_time
    ,b.update_time
    ,b.apply_seq
    ,CASE WHEN b.apply_seq = 1 THEN 1 ELSE 0 END              AS is_first_apply_in_window
    ,e.strategy_time
    ,e.retry_count
    ,b.dw_cre_date
    ,b.dw_upd_date
FROM base b
LEFT JOIN (
    SELECT
         loan_no
        ,application_id
        ,app_id
        ,CAST(inserttime AS TIMESTAMP) AS strategy_time
        ,CAST(retry_count AS INT)      AS retry_count
    FROM model.tmp_eliam_wagego_application
    WHERE event_type = 'loan_apply'
      AND loan_no LIKE 'LN%'
) e
  ON b.loan_no = e.loan_no
;
```

## 验收

```sql
SELECT COUNT(*)                 AS apply_cnt,
       COUNT(DISTINCT loan_no)  AS loan_no_cnt,
       COUNT(DISTINCT user_id)  AS user_cnt,
       SUM(is_disburse_success) AS disburse_success_cnt,
       SUM(is_reject)           AS reject_cnt,
       SUM(is_expired)          AS expired_cnt,
       SUM(is_disburse_failed)  AS disburse_failed_cnt,
       SUM(is_processing)       AS processing_cnt,
       SUM(is_first_apply_in_window) AS first_apply_cnt,
       SUM(CASE WHEN strategy_time IS NULL THEN 1 ELSE 0 END) AS no_strategy_cnt,
       MIN(apply_time)          AS min_apply_time,
       MAX(apply_time)          AS max_apply_time
FROM model.tmp_eliam_wagego_loan_apply;
```

预期（导出时点）：`apply_cnt = loan_no_cnt = 33,491`；`user_cnt = first_apply_cnt = 15,621`；`disburse_success_cnt = 25,549`；`reject_cnt = 5,517`；`expired_cnt = 2,280`；`disburse_failed_cnt = 137`；`processing_cnt = 6`；`no_strategy_cnt = 27`。

```sql
SELECT apply_status, apply_status_desc, COUNT(*) AS cnt
FROM model.tmp_eliam_wagego_loan_apply
GROUP BY apply_status, apply_status_desc
ORDER BY cnt DESC;
```
